# Примитивная база данных

Консольная база данных на Python 3.12+. Поддерживает создание и удаление таблиц,
CRUD-операции, типы `int`, `str`, `bool` и хранение данных в JSON.

## Установка и запуск

Из папки репозитория:

```sh
uv sync
uv run database
```

Также доступны `uv run project` и `uv run python -m primitive_db.main`.

## Управление таблицами

```text
create_table users name:str age:int is_active:bool
list_tables
info users
```

Столбец `ID:int` добавляется автоматически. Имена таблиц и столбцов должны быть
идентификаторами Python. Данные хранятся в `data/<таблица>.json`, структура таблиц
в `db_meta.json` в рабочей папке.

## CRUD-операции

```text
insert into users values ("Sergei", 28, true)
select from users
select from users where age = 28
update users set age = 29 where name = "Sergei"
delete from users where ID = 1
y
drop_table users
y
exit
```

Все поля обязательны. Значения передаются в порядке объявления столбцов, без ID.
Строки заключаются в одинарные или двойные кавычки, логические значения записываются
как `true` и `false`. Для кавычки внутри строки используется другой вид кавычек
снаружи. Обратная косая черта для экранирования кавычек не поддерживается.

Новый ID равен `max(ID) + 1`, для пустой таблицы используется 1. После удаления
максимального ID его номер может использоваться снова. Изменять ID нельзя.
`where` поддерживает одно равенство, `set` допускает несколько присваиваний через
запятую. Справка доступна по команде `help`.

Удаление таблиц и записей требует подтверждения `y`. Остальные ответы отменяют
операцию. Декораторы обрабатывают ошибки и выводят время выполнения `insert` и
`select`. Повторные выборки кэшируются через замыкание, при изменении данных
используется новый ключ кэша.
